Тестирование функциональности сайта  stellarburgers расположенного  на https://stellarburgers.education-services.ru/login 

В проекте были написаны авто тесты на  следующий функционал приложения:

    test_successful_registration - Проверяет успешную регистрацию нового пользователя с валидными данными (имя не пустое, email в формате логин@домен, пароль 6 символов). После регистрации проверяет редирект на страницу входа

    test_registration_invalid_password - Проверяет появление ошибки "Некорректный пароль" при регистрации с паролем менее 6 символов

    test_multi_page_login - Проверяет вход через кнопки:
        "Войти в аккаунт" на главной странице
        "Личный Кабинет" на главной странице
        "Войти" на форме регистрации
        "Войти" на форме восстановления пароля

    test_click_through_to_personal_account - Проверяет переход в личный кабинет по клику на кнопку "Личный Кабинет"

    test_from_personal_account_to_constructor - Проверяет переход из личного кабинета в конструктор по клику:
        на логотип Stellar Burgers
        на кнопку "Конструктор"

    test_exit_account - Проверяет выход из аккаунта по кнопке "Выйти" в личном кабинете

    test_switching_between_sections - Проверяет в конструкторе перехо по разделам

Были сделаны фикстуры:

    driver - Создает и закрывает драйвер Chrome. Открывает окно на весь экран, устанавливает неявное ожидание 5 секунд

    base_url - Возвращает базовый URL сервиса Stellar Burgers

    existing_user - Возвращает данные существующего пользователя (email и пароль) для тестов входа

    login - Выполняет авторизацию пользователя перед тестом. Возвращает драйвер с уже авторизованной сессией. Используется в тестах, где требуется авторизованный пользователь.
